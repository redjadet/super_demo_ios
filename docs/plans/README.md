# Plans

Executable plans live **only on your machine**. Plan markdown under
`docs/plans/` and `docs/superpowers/plans/` is gitignored.

Store plans here when work is too large for a single obvious patch.

Good plans include:

- goal,
- scope,
- phased steps,
- validation per phase,
- stop criteria,
- rollback notes when relevant.

Do not commit plan files. Specs or shipped design decisions that must be
shared belong in tracked docs (for example `docs/changes/` or
`docs/superpowers/specs/` when intentionally published).
