# 2026-09-26 — CI pins Xcode 27 (latest released on GHA)

## Summary

Hosted Delivery checklist + release-smoke move from `macos-26` / Xcode 26.6 to
the `xcode-27` runner image and select the newest **released** Xcode (≥ 27).

## Why

- README / local toolchain already document **Xcode 27** / Swift 6.4 / iOS SDK 27.
- GHA `macos-26` tops out at released **26.6**; Xcode 27 ships on the `xcode-27`
  image ([runner-images#14404](https://github.com/actions/runner-images/issues/14404)).
- On that image, **27.1** (GM build `27A9269`) is preferred over seed **27.0**
  (`27A266a`) and beta **27.2**.

## Changes

- `.github/workflows/ci.yml` + `release-smoke.yml`: `runs-on: xcode-27`,
  `SUPER_DEMO_XCODE_MIN_VERSION=27`, early `source ./tool/select_xcode.sh`.
- `tool/select_xcode.sh`: treat Apple ProductBuildVersion as authoritative for
  released vs seed/beta (GHA may keep `_beta` in app paths after GM).
- Docs: [`ci-cd-map.md`](../ci-cd-map.md), [`agent_project_context.md`](../agent_project_context.md).

## Escape

`runs-on: macos-26` + `SUPER_DEMO_XCODE_MIN_VERSION=26.5` (typically 26.6).

## Coordination

Separate from UITest-heavy [#29](https://github.com/redjadet/super_demo_ios/pull/29)
(sim selection / `CI_IPHONE_GENERIC_BUILD`); rebase that PR after this lands.
